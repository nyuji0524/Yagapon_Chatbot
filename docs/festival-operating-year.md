# 矢上祭の年度区分

矢上祭実行委員会のナレッジでは、毎年10月1日に年度（回次）を切り替え、翌年9月30日までを同じ回次として扱う。

| 回次 | 開始日 | 終了日 |
| --- | --- | --- |
| 26th | 2024-10-01 | 2025-09-30 |
| 27th | 2025-10-01 | 2026-09-30 |
| 28th | 2026-10-01 | 2027-09-30 |

一般に、`N th` の開始年は `N + 1998` 年となる。この区分は検索・記録分類のための契約であり、実際の引継ぎや担当交代の日付とは区別する。

したがって、2026-09-30は27th、2026-10-01は28thに属する。複数の日付を回次判定する場合も、それぞれの日付にこの規則を個別に適用する。
